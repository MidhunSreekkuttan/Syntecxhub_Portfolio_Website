# 🌐 Portfolio

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript. It showcases my technical skills, featured projects, and contact information through a clean, dark-themed interface.

## ✨ Features

- **Hero Section** — Introduction and quick navigation to projects and contact details.
- **Skills Section** — Highlights technical skills and development tools.
- **Featured Projects** — Displays projects with descriptions, technology tags, and GitHub or live project links.
- **Contact Section** — Provides email, GitHub, and LinkedIn links.
- **Responsive Design** — Adapts to desktop, tablet, and mobile screen sizes.
- **Lucide Icons** — Uses clean, lightweight icons to enhance the interface.
- **Smooth Scrolling** — Provides smooth navigation between page sections.
- **Hover Effects** — Adds interactive visual feedback to cards, buttons, and links.
- **Accessibility Support** — Includes semantic HTML, accessible icon handling, keyboard focus indicators, and reduced-motion support.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic markup |
| CSS3 | Styling, layouts, animations, and responsive design |
| JavaScript | Icon initialization and dynamic icon rendering |
| Lucide | Lightweight interface icons |

## 🚀 Getting Started

### Prerequisites

You need a modern web browser and a code editor such as Visual Studio Code.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/MidhunSreekkuttan/portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd portfolio
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code to run the website locally.

> **Note:** Replace the repository URL above if your portfolio repository uses a different name.

## ⚙️ Customization

You can personalize the portfolio by editing the following files:

- **`index.html`** — Update your introduction, skills, project details, social links, and contact email.
- **`style.css`** — Customize colors, typography, spacing, card layouts, and responsive behavior.

The primary theme colors are defined using CSS custom properties:

```css
:root {
    --bg: #0b1120;
    --surface: #141d30;
    --surface-hover: #1b2940;
    --primary: #a78bfa;
    --secondary: #67e8f9;
    --text: #f1f5f9;
    --muted: #94a3b8;
    --border: #29364d;
}
```
